# Location Scouting

Where we're shooting *Une Faible Impression*, and what to know before we get there.

## How this works

1. Copy `_template.md` into `locations/` for each new site, name it something like `01-apartment-interior.md`.
2. Fill it in as you scout — photos go in `locations/photos/<location-slug>/`.
3. Once a location is confirmed, add it as a row in the breakdown table below.

## Location breakdown

| # | Location | Scenes | Status | Report |
|---|----------|--------|--------|--------|
| 1 | | | scouting / pending permit / confirmed | [locations/](locations/) |

Status values: `scouting`, `pending permit`, `confirmed`, `backup`.

## Folders

- `locations/` — one report per location (see `_template.md`)
- `locations/photos/` — reference photos, subfoldered by location slug
